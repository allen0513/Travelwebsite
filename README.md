# 浙里风光旅游网

## 项目简介

"浙里风光"是一个专注于浙江旅游的综合性网站，旨在为游客提供全面的浙江旅游信息和服务。网站涵盖了浙江各地的旅游景点、美食文化、住宿推荐、旅游攻略等内容，帮助用户深入了解浙江的自然风光和人文底蕴。

## 功能特色

### 🌏 旅游目的地
- 覆盖浙江省11个城市的旅游导航
- 热门景点详细介绍（良渚古城、灵隐寺、千岛湖等）
- 按城市分类的景点展示

### 🍜 美食地图
- 浙菜文化介绍（中国八大菜系之一）
- 杭州、宁波、绍兴等地特色美食
- 详细的美食卡片展示（图片、描述、价格）

### 🏨 住宿推荐
- 各类住宿选择推荐
- 不同档次的酒店民宿信息

### 📝 旅游攻略
- 四季旅游指南（春踏青、夏避暑、秋赏景、冬养生）
- 详细的行程规划建议
- 实用的旅行贴士

### 🎯 交互功能
- 响应式轮播图展示
- 滚动公告栏系统
- 搜索功能
- 返回顶部按钮
- 预订弹窗功能

## 安装与运行

### 本地运行
由于这是一个纯静态网站，您可以直接通过以下方式运行：

1. **直接打开**
   ```bash
   # 直接在浏览器中打开 index.html 文件
   ```

2. **使用本地服务器（推荐）**
   ```bash
   # 使用 Python
   python -m http.server 8000
   
   # 或使用 Node.js 的 http-server
   npx http-server
   
   # 然后访问 http://localhost:8000
   ```

3. **使用 VS Code Live Server**
   - 安装 Live Server 扩展
   - 右键点击 index.html
   - 选择 "Open with Live Server"

## 设计规范

### 色彩方案
- **主色调**: 绿色系 (#4CAF50, #45a049) - 代表自然、生态
- **辅助色**: 
  - 红色系 (#ff6b6b) - 用于强调和促销
  - 蓝色系 (#667eea, #764ba2) - 用于公告栏
  - 橙色 (#FF9800) - 用于价格和标签

### 字体
- 主要字体: Microsoft YaHei, Arial, sans-serif
- 标题字号: 2.5rem (section-title)
- 正文字号: 1rem - 1.1rem

### 间距系统
- 大间距: 80px (section padding)
- 中间距: 40px, 60px
- 小间距: 15px, 20px, 30px

### 圆角规范
- 卡片圆角: 10px - 15px
- 按钮圆角: 20px - 28px
- 头像圆角: 50% (圆形)

## 响应式设计

### 断点
- **桌面端**: > 768px
